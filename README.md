## 🚀 Selected Projects

### 🦠 [Cuckoo Ops Center (Master's Thesis)]
An advanced orchestration platform built on top of **Cuckoo Sandbox**. Designed to reintroduce the *"Human-in-the-Loop"* paradigm, it solves the limitations of traditional sandboxes against context-aware threats.
* **Highlights:** Heuristic static analysis via Radare2, asynchronous Zero-RAM live monitoring (simulated `tail`), automatic ZIP extraction, and automated behavior mapping to the **MITRE ATT&CK** framework.

### 🔐 Def-Net
An application designed for cybersecurity and network analysis, focusing on monitoring and defending against common attack vectors.
